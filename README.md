A Library Management System built using Python, FastAPI, SQLAlchemy, Pydantic, and PostgreSQL.

The application provides RESTful APIs to manage books, users, and borrowing records. It supports CRUD operations, secure password hashing, book availability tracking, borrowing and returning books, overdue book tracking, and book search functionality.

Key Features:

Book and User Management (CRUD operations)

Password validation and hashing using Argon2

Book borrowing and returning functionality

Automatic tracking of available book copies

Borrowing history by user

Overdue book tracking

Book search by title and author

Asynchronous database operations using SQLAlchemy and PostgreSQL
